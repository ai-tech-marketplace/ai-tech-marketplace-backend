# AI Tech Marketplace — Backend

Backend service for AI Tech Marketplace.

## Technology

* Java
* Spring Boot
* Spring Security
* PostgreSQL
* Redis
* Apache Kafka
* Flyway
* Docker

## Responsibilities

The backend owns:

* Authentication
* Authorization
* Users
* Products
* Categories
* Brands
* Cart
* Orders
* Inventory
* Public REST APIs
* AI orchestration

## Architecture

```text
React
  |
  v
Spring Boot
  |
  ├── PostgreSQL
  ├── Redis
  ├── Kafka
  └── Python AI Service
```
